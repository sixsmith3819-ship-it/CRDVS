  - Advanced filtering interface

  - Core feature for identity checks
  - Search by National ID, name, or date of birth
  - Fuzzy matching for similar names
  - Visual indicators for:

    - Fuzzy matches (yellow warning)
    - No records found (green clear)
  - Detailed results with all record information
  - Direct links to full record details

- **Verification API** (`/api/verify`)
  - Server-side verification logic
  - Exact and fuzzy matching algorithms
  - Automatic logging of all verification requests
  - Audit trail creation
  - Confidence score calculation

### 5. Reports Management

  - View all generated verification reports

  - Status indicators (valid/invalid)

## Data Flow

### Verification Flow
1. User enters search criteria (National ID, name, DOB)
2. Form submits to `/api/verify` endpoint
3. API searches database for matches
4. Exact matches checked first (National ID, name+DOB)
5. Fuzzy matches checked if no exact matches
6. Verification request logged to database
7. Audit log entry created
8. Results returned with confidence score
9. UI displays results with appropriate styling

### Authentication Flow
1. User enters credentials on `/login`
2. Server action validates credentials
3. Supabase creates session
4. User redirected to `/dashboard`
5. Middleware protects all `/dashboard/*` routes
6. Session checked on each request
7. Profile loaded for role-based features
